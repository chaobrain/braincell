Contributor Guide
=================

This guide organizes contribution tasks, from setting up a development environment
and locating code to validating changes and submitting a pull request.
Module interfaces, parameters, and equations are documented in the docstrings that
the API reference renders.

For your first contribution, start with :doc:`contributing`. If you already have a
specific task, go directly to its topic. :doc:`project_layout` maps the directories
and where to start for a given change; :doc:`conventions` holds the code rules.
