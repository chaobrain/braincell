# BrainCell / Jaxley / NEURON simulator comparison

This benchmark reproduces the workload behind the Jaxley/NEURON timing panel and
adds BrainCell under an explicit fairness contract. The historical figure is assembled
in `/home/swl/jaxley_experiments/nex/fig2_demonstration/notebooks/02_assemble_figure.ipynb`;
its timing data was generated by `00_timing.ipynb`.

## Fairness contract

- The byte-identical `n144.swc` asset comes from the Jaxley experiment and has SHA256
  `68af99cf829e22005b2177b3d2ff4316bdaec2fcf0f1e4b85f81cdd2a8c01069`.
- All backends use 217 branches, four CVs per branch (868 CVs), classic HH at 6.3 C,
  `dt=0.025 ms`, `tstop=20 ms`, and the same clamp and recording locations.
- BrainCell and Jaxley run independent batches on the same physical GPU, selected only
  from GPU 2 and 3. They run sequentially in isolated processes.
- NEURON is CPU serial and is never run above N=10. N=100, N=1000, and N=10000 are linear
  projections from the measured N=10 distribution and are visibly marked as such.
- Model construction and compilation are reported separately. Steady-state timings cover
  state restoration, 800 updates, and synchronization of three voltage traces. Full
  device-to-host transfer time and peak GPU memory are reported separately.
- A failed voltage/spike accuracy gate prevents generation of the performance plot.

The source SWC is redistributed here solely as a benchmark fixture from the adjacent
Jaxley experiments repository. Preserve its provenance and checksum when replacing it.

## Environment

Both GPU backends should use one Python/JAX installation. On this machine the prepared
environment is `/home/swl/anaconda3/envs/braincell_311`, with Python 3.11 and JAX 0.10.1.
The local `/home/swl/jaxley` checkout is installed editable into that environment.
NEURON uses `/home/swl/anaconda3/envs/neuron`.

Verify the shared stack:

```bash
/home/swl/anaconda3/envs/braincell_311/bin/python -c \
  "import braincell,jax,jaxley; print(braincell.__version__, jax.__version__, jaxley.__version__)"
```

## Run

Full comparison:

```bash
cd /home/swl/braincell/examples/profiling/simulator_compare
/home/swl/anaconda3/envs/braincell_311/bin/python run_benchmark.py \
  --batch-sizes 10,100,1000,10000 \
  --gpu-candidates 2,3 \
  --braincell-linearizer point \
  --output results/benchmark_10000.json
```

BrainCell defaults to the point-local membrane linearizer. Use
`--braincell-linearizer generic` for an A/B run of the retained whole-CV AD path.

Fast smoke run (still only GPU 2 or 3, and no NEURON above N=10):

```bash
/home/swl/anaconda3/envs/braincell_311/bin/python run_benchmark.py \
  --batch-sizes 10 --warmup 0 --repeat 1 \
  --neuron-warmup 0 --neuron-repeat 1 \
  --output results/smoke.json
```

The run writes raw backend JSON files plus aggregate JSON, CSV, PNG, and SVG outputs.
When both GPU backends are present it also writes the diagnostic figures described below.
Filled markers are measured values; hollow NEURON markers are extrapolated.
The primary performance plot reports speedup as the matched-size NEURON median
runtime divided by each backend's median runtime, so NEURON is the 1x baseline.
The JSON also records whether each backend is JIT compiled, its synchronization boundary,
cell-steps/s, full host-transfer timings, peak GPU memory, and an affine scaling fit.

Generate diagnostic plots from an existing result without rerunning any simulator:

```bash
/home/swl/anaconda3/envs/braincell_311/bin/python plot_diagnostics.py \
  results/benchmark_10000_gpu2.json \
  --output-prefix results/benchmark_10000_gpu2
```

This writes separate cold-start, peak-memory, throughput, full-output-transfer,
timing-variability, and effective-transfer-rate figures, plus a combined dashboard
and a numerical-accuracy figure when the accuracy gate was run, plus a CSV containing
the derived values. Transfer error bars are the IQR of three
copies. Runtime error bars use seven steady-state samples. GPU memory is one allocator
high-water mark per isolated process, so no memory error bar is reported.

Run implementation tests without starting a full benchmark:

```bash
/home/swl/anaconda3/envs/braincell_311/bin/python -m pytest -q test_simulator_compare.py
```
